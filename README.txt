LA BELLA RESTAURANT - HTML/CSS/BOOTSTRAP PROJECT

Pages:
1. index.html          - Home
2. menu.html           - Menu
3. dish-detail.html    - Dish Detail
4. reservation.html    - Reservation
5. signup.html         - Signup
6. login.html          - Login

Folders:
css/style.css          - External CSS
js/script.js           - Minimal JavaScript

Framework:
Bootstrap 5.3.3 via CDN

Libraries:
jQuery 3.7.1 is used only on Dish Detail for the required image zoom.

How to run with Laragon:
1. Put the restaurant_project folder inside C:\laragon\www\
2. Start Laragon.
3. Open http://localhost/restaurant_project/
4. Internet is needed for Bootstrap, jQuery and Unsplash images because this project uses CDN/external image resources.

Note:
Forms are front-end demonstrations only; no PHP/database/backend processing is included.
